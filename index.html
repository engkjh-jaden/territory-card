📥 Excel 이관

📥 기존 Excel 구역 데이터 일괄 이관

기존 데이터를 삭제하지 않고 복사합니다. Excel의 여러 파일과 여러 시트를 한 번에 선택할 수 있습니다. 먼저 미리보기로 구역·건물·방문 대상을 확인한 뒤 가져오세요.

📍 NAVER 지도 테스트

NAVER 지도 API v3의 최신 방식인 ncpKeyId를 사용합니다. Client ID와 웹 서비스 URL 등록이 필요합니다.

등록된 구역 지도

Excel을 처음 이관하거나 수정본을 다시 이관하면 건물 주소의 좌표를 자동으로 저장합니다. 좌표가 없는 건물만 NAVER Geocoding을 사용합니다.
Client ID를 저장한 뒤 [지도 불러오기]를 누르세요.
테스트 지도에서 클릭한 위치의 위도·경도를 확인하고, 주소 검색 결과를 확인할 수 있습니다. Excel에서 이관된 건물 좌표와 마커를 불러올 수 있습니다. 세대/현관 위치는 필요할 때 별도로 저장할 수 있습니다.

안내

방문 기록에는 가능한 한 필요한 최소 정보만 입력하세요. 개인의 이름, 민감한 종교적 반응 등 불필요한 개인정보를 기록하지 않는 것을 권장합니다.

지도는 네이버 지도 검색 링크를 사용합니다. 구역 경계선(폴리곤)을 실제 지도 위에 표시하는 기능은 다음 단계에서 추가할 수 있습니다. NAVER 지도 테스트는 관리자 메뉴에서 Client ID를 입력해 확인할 수 있습니다.
